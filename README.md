# 📻 Интернет-радио от Августа

Инструкция и веб-страница для запуска собственного интернет-вещания с помощью связки **Icecast + Clementine + butt** и туннеля через **localhost.run**.

## 🚀 Что здесь есть:
* Пошаговое руководство по настройке локального сервера Icecast.
* Инструкция по трансляции музыки, тегов и обложек через Clementine и butt.
* Прямой плеер для прослушивания эфира прямо в браузере.

## 🛠️ Стек технологий:
* **Аудио-сервер:** Icecast2
* **Плеер / Источник:** Clementine
* **Поток:** butt (broadcast using this tool)
* **Туннель:** localhost.run (SSH)
